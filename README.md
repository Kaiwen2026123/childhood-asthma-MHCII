# childhood-asthma-MHCII
R scripts for single-cell RNA-seq analysis of BALF and PBMC in childhood asthma, associated with the submitted manuscript.

## Analysis scripts
- 01_bulk_pipeline.R: Bulk transcriptome analysis pipeline
- 02_single_cell.R: Single-cell RNA-seq analysis of BALF and PBMC
- 03_revision_analyses.R: Additional analyses for manuscript revision

## Computational environment
All R packages and version information are documented inside each script.
Main packages: Seurat, limma, WGCNA, CellChat, ConsensusClusterPlus.
